# Project Overview

This is a web-based Service Portal that allows users to submit, track, and manage service requests; built with React Typescript frontend, Python FastAPI backend, and Postgres database as the stack.

## Phase 1: Foundations & Project Setup

### Requirements:

Set up project structure (Frontend, Backend, Database).
Design database schema for users, service requests, comments, and status tracking.
Configure local development environment.
Implement authentication and role definitions (User/Admin).

### Deliverable:

Database schema and working project skeleton.

## Phase 2: Frontend Development

### Requirements:

Develop responsive user interface using React/Angular.

### Create pages for:

Login/Register
Submit Service Request
View Request Details
Track Request Status
User Dashboard
Implement form validations and navigation.

### Deliverable:

Fully functional UI integrated with mock data.

## Phase 3: Backend Development

### Requirements:

Build REST APIs for:
Authentication
Service Request CRUD operations
Status updates and comments
Integrate database.
Implement security, logging, and API documentation (Swagger/OpenAPI).

### Deliverable:

Secure backend services connected to the database.

## Phase 4: DevOps & Cloud Deployment

### Requirements:

Containerize application using Docker.
Create CI/CD pipeline (GitHub Actions/Azure DevOps).
Configure development and production environments.
Deploy application to cloud platform (Azure/AWS).

### Deliverable:

Automated deployment pipeline and live application.

## Phase 5: AI-Powered Chat Integration

### Requirements:

Integrate AI chatbot using OpenAI

### Supports:

FAQs
Service request creation
Ticket status lookup
Basic troubleshooting guidance
Connect chatbot to backend APIs.

### Deliverable:

AI assistant available within the portal.

## Phase 6: Integration, Testing & Capstone

### Requirements:

Perform end-to-end integration testing.
Conduct functional, security, and performance testing.
Fix defects and optimize user experience.
Prepare deployment documentation and demo scenarios.

### Deliverable:

Production-ready Service Portal with AI chatbot and stakeholder demo.
